Changelog

A record of what's actually changed in ZettelNote — not a marketing blog, just the features we shipped and the bugs we fixed.

August 2026 — Added English UI support

The entire app is now available in English, too. The display language is detected automatically from your browser or OS settings (you can also switch it manually with the language button).

August 2026 — Improved reliability

Updated our infrastructure so deploying updates no longer causes any downtime.

August 2026 — Added a login-free local mode

You can now try creating notes and see related notes in action before signing up for an account. Everything stays on your device — nothing is sent anywhere.

August 2026 — Improved multi-device sync

Fixed a bug where changes made on one device wouldn't always show up on another. Also tuned how often devices sync automatically, so the latest version reaches you faster.

August 2026 — Added semantic search

You can now find related notes even when the exact wording doesn't match. Choose a lightweight setting, or a more accurate one (which takes a moment to set up the first time).

Earlier

Zettelkasten-style note organization, real-time related notes, zero-knowledge encryption, and both desktop (Electron) and web (PWA) apps.
